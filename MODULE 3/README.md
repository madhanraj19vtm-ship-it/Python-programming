# MODULE 3 - Lab Practice

This folder contains the Python programs for Module 3 Lab Practice.

## Contents

### Lab Exercise 1 - Contact Book using Lists and Dictionaries
`lab_exercise_1_contact_book.py`

A menu-driven contact book that stores contact details in a list of dictionaries and supports adding, viewing, and searching contacts.

### Lab Exercise 2 - Student Grading System
`lab_exercise_2_student_grading_system.py`

Accepts marks for multiple subjects and calculates total marks, average, grade, and pass/fail status.

### Lab Exercise 3 - Frequency Counter using Dictionaries
`lab_exercise_3_frequency_counter.py`

Counts the frequency of letters and numbers in a word or sentence using a dictionary.

### Mini Project - Attendance Tracker
`mini_project_attendance_tracker.py`

A menu-driven attendance tracker that stores students, records daily attendance, and generates attendance percentages.

## How to Run

Make sure Python 3 is installed, then run any program from this folder:

```bash
python filename.py
```

Example:

```bash
python lab_exercise_1_contact_book.py
```
