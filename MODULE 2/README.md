# MODULE 2 - Lab Practice

This folder contains the Python programs for Module 2 Lab Practice (6 Hours).

## Contents

### Lab Exercise 1 - Number Guessing Game
`lab_exercise_1_number_guessing_game.py`

A simple game where the computer selects a random number from 1 to 100 and the user keeps guessing until the correct number is found.

### Lab Exercise 2 - Prime Number and Factorial
`lab_exercise_2_prime_and_factorial.py`

Checks whether a number is prime and calculates the factorial of a non-negative integer using loops.

### Lab Exercise 3 - Fibonacci Series Using Recursion
`lab_exercise_3_fibonacci_recursion.py`

Generates the Fibonacci series using a recursive function.

### Mini Project - Student Grading Automation
`mini_project_student_grading_automation.py`

Accepts marks for five subjects and automatically calculates total marks, average, grade, and pass/fail status.

## How to Run

Make sure Python 3 is installed, then run any program from this folder:

```bash
python filename.py
```

Example:

```bash
python lab_exercise_1_number_guessing_game.py
```
