# MODULE 1 - Python Fundamentals

This folder contains the programs for Module 1 lab exercises and the mini project.

## Contents

### Lab Exercise 1 - Basic Python Program
`lab_exercise_1_basic_python.py`

A simple Python program demonstrating basic output using `print()`.

### Lab Exercise 2 - Variables, Operators, and Input/Output
`lab_exercise_2_variables_operators_io.py`

Demonstrates variables, user input, type conversion, arithmetic operators, and formatted output.

### Lab Exercise 3 - Simple Calculator and Area Calculations
`lab_exercise_3_calculator_area.py`

Contains a simple calculator and area calculations for a circle, rectangle, and triangle.

### Mini Project - Unit Converter
`mini_project_unit_converter.py`

A menu-driven unit converter for length, weight, and temperature.

## How to Run

Make sure Python 3 is installed, then run any program from this folder:

```bash
python filename.py
```

Example:

```bash
python lab_exercise_1_basic_python.py
```
